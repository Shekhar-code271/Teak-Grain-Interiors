# 🪵 Teak & Grain Interiors Website

A fully responsive, feature-packed web application built for **Teak & Grain Interiors**, a custom interior design and solid teak woodcraft provider located in Vadodara, Gujarat. 

## ✨ Key Features

* **Interactive 3D Room Preview:** Built using Three.js, giving visitors an interactive 3D model view with toggleable room lighting and real-time wood finish customisation (Teak, Walnut, Oak, and White).
* **Hash-Based Page Routing:** Smoothly manages multiple sections and views (Home, Services, Portfolio, About, and Contact) within a clean single-file architecture.
* **Dynamic Cost Estimator:** An interactive calculator enabling users to select specific interior services, adjust area square footage via range sliders, choose package tiers (Essential, Signature, Luxe), and generate indicative cost ranges.
* **Before & After Visual Slider:** An interactive image comparison element that lets users drag across a slider to view a room's transformation.
* **WhatsApp Direct Integration:** Contact and estimate forms that automatically format client details and redirect directly to WhatsApp for fast communication[cite: 15].
* **Modern UI & Animations:** Features interactive card tilt effects on mouse movement, animated numerical stat counters, a scrolling service marquee, dark/light theme adaptation, and mobile-optimised floating action buttons[cite: 15].

## 📁 Project Structure

The entire application is consolidated into a single file for easy deployment:
* `index.html`: Contains all HTML markup, responsive CSS variables, interactive widgets, form handlers, and Three.js rendering scripts[cite: 15].
